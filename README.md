# Food Delivery Insights Dashboard - Power BI

## 📊 Project Overview
This project presents a **Power BI dashboard** that provides key insights into food delivery orders, analyzing various factors such as cuisine preferences, order distribution, delivery duration, and more. The dashboard visually represents trends that can help businesses optimize their food delivery operations and enhance customer satisfaction.

## 🚀 Features & Insights
- **Cuisine Popularity Analysis**: Identifies the percentage of total orders by cuisine type.
- **Order Trends by Restaurant Type**: Displays how different restaurant categories perform in terms of order volume.
- **Day-wise Order Distribution**: Shows which days of the week experience the highest and lowest order volumes.
- **Number of Items per Order**: Analyzes order sizes to understand customer purchasing behavior.
- **Order Subtotal Distribution**: Provides insights into the price distribution of food orders.
- **Store-to-Customer Driving Duration**: Examines delivery time trends from restaurants to customers.
- **Total Delivery Duration Analysis**: Helps assess the efficiency of the food delivery process.

## 📂 Dataset
The dataset contains transaction-level details from a food delivery platform, including:
- Order subtotal values
- Cuisine types and restaurant categories
- Delivery times and distances
- Number of items ordered
- Order day trends

## 🛠 Tools & Technologies
- **Power BI**: Data visualization and interactive dashboard creation
- **Excel/CSV**: Data preprocessing and organization
- **DAX (Data Analysis Expressions)**: Custom calculations in Power BI


## 🎯 Use Cases
- Restaurants can optimize their menu offerings by identifying popular cuisines.
- Food delivery companies can analyze delivery times to improve efficiency.
- Market analysts can study consumer behavior in the food delivery sector.
